# 本地业务服务容器化部署

## 部署前准备

1. 进入基础镜像[目录](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-docker-image/maozi-cloud-base-jdk-image)执行
   ```
   docker buildx build -f Dockerfile -t maozi-cloud-base-jdk:1.0.0 .
   ```
2. 进入业务基础镜像[目录](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-docker-image/maozi-cloud-business-jdk-image)执行
   ```
   docker buildx build -f Dockerfile -t maozi-cloud-business-jdk:1.0.0 .
   ```
3. 该[文件](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-docker-image/maozi-cloud-services.json)中的`"dubbo_ip_to_registry": "192.168.124.3"`修改为物理机IP,该配置作用为物理机的业务服务能访问到容器内的业务服务，若确定物理机的业务服务不会调用到容器内的业务服务可以直接注释掉`"dubbo_ip_to_registry": "192.168.124.3"`和`"dubbo_flag": "-DDUBBO_IP_TO_REGISTRY=${DUBBO_IP_TO_REGISTRY}"`
4. 该[文件](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-docker/maozi-cloud-distributeds-docker/maozi-cloud-services-distributeds-docker.yml)中所有的`/Users/maozi/Desktop/maozi-cloud-logs`修改为该[文件](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-docker/maozi-cloud-basics-docker/docker-compose.yml)中的原值为`/Users/maozi/Desktop/maozi-cloud-logs`修改后的新值一致

## 全量部署

1. 单体服务[bat脚本](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-run/maozi-cloud-deploy-bat-run/maozi-cloud-deploy-services-monomer.bat)执行
2. 单体服务[shell脚本](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-run/maozi-cloud-deploy-shell-run/maozi-cloud-deploy-services-monomer.sh)执行
3. 微服务[bat脚本](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-run/maozi-cloud-deploy-bat-run/maozi-cloud-deploy-services-distributed-force.bat)执行
4. 微服务[shell脚本](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-run/maozi-cloud-deploy-shell-run/maozi-cloud-deploy-services-distributed-force.sh)执行
5. 单体跟微服务不能同时启动,会导致端口冲突 需要修改网关或单体服务的端口号

2. 微服务[shell脚本](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-run/maozi-cloud-deploy-shell-run/maozi-cloud-deploy-services-distributed.sh)执行
