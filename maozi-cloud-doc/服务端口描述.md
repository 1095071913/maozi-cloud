# 服务端口描述

> - 前端服务与业务服务均以 **随机端口** 启动，并注册到 Nacos 注册中心，实际端口以 Nacos 控制台查询结果为准
> - 对外访问统一经由 Nginx 网关（80 端口）入口，按路由规则转发至各服务

## 网关服务

| 服务                           | 端口 | 说明                     |
| :----------------------------- | :--: | :----------------------- |
| maozi-cloud-nginx-monomer      |  80  | 单体版 Nginx 网关，统一流量入口 |
| maozi-cloud-nginx-distributeds |  80  | 分布式版 Nginx 网关，统一流量入口 |

## 前端服务

| 服务                            | 端口 | 说明                           |
| :------------------------------ | :--: | :----------------------------- |
| maozi-cloud-admin-monomer       | 随机 | 单体版管理后台前端【网关路由 /admin】             |
| maozi-cloud-admin-distributeds  | 随机 | 分布式版管理后台前端【网关路由 /admin】           |

## 业务服务

| 服务                          | 端口 | 说明               |
| :---------------------------- | :--: | :----------------- |
| maozi-cloud-service-monomer   | 随机 | 单体版整合业务服务【网关路由:/api】 |
| maozi-cloud-gateway-service   | 随机 | 业务 API 网关服务【网关路由:/api】  |
| maozi-cloud-monitor-service   | 随机 | 监控服务           |
| maozi-cloud-oauth-service     | 随机 | 认证授权服务       |
| maozi-cloud-system-service    | 随机 | 系统管理服务       |
