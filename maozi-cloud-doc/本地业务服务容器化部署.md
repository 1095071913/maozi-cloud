# 本地业务服务容器化部署

## 部署前准备

1. 进入基础镜像[目录](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-docker-image/maozi-cloud-base-jdk-image)执行
   ```
      docker buildx build -f Dockerfile -t maozi-cloud-base-jdk:1.0.0 .
   ```
2. 进入业务基础镜像[目录](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-docker-image/maozi-cloud-business-jdk-image)执行
   ```
   docker buildx build -f Dockerfile -t maozi-cloud-business-jdk:1.0.0 .
   ```
3. 在[目录](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-docker/maozi-cloud-business-docker)中创建.env设置业务服务环境变量
   ```
   # JVM参数设置
   JVM_PARAMS=-Xms256m -Xmx256m -Xss256k -XX:MaxMetaspaceSize=256m -XX:+UseSerialGC -XX:CompressedClassSpaceSize=32m -XX:ReservedCodeCacheSize=32m -XX:MaxDirectMemorySize=128m
   
   # 环境设置，默认dev
   ENVIRONMENT=dev
   
   # 灰度标识，默认main
   VERSION=main
   
   # 网关端口，默认80
   GATEWAY_PORT=80
   
   # 业务服务向注册中心注册的地址，默认容器IP
   TO_REGISTER_IP=192.168.xxx.xxx
   
   # 百炼云密钥
   AI_DASHSCOPE_KEY=xxx
   
   # 阿里云标识
   ALIYUN_CLIENT_ID=xxx
   
   # 阿里云密钥
   ALIYUN_CLIENT_SECRET=xxx
   ```

## 网关部署

1. 进入[目录](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-docker/maozi-cloud-business-docker)
2. 单体服务: `docker compose -f maozi-cloud-nginx-monomer-docker.yml up -d`
3. 微服务: `docker compose -f maozi-cloud-nginx-distributeds-docker.yml up -d`
