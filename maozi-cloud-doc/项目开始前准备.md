# 项目开始前准备

1. 容器化部署

   |操作系统|安装内容|
   |--|--|
   |Linux|Docker、Docker Compose|
   |Windows|WSL2、Docker Desktop|
   |MacOS|Docker Desktop|

2. （可选）项目控制台[安装包](https://github.com/1095071913/maozi-cloud/releases/download/20261005190000/maozi-cloud-develop-admin-1.0.0-arm64.dmg)，帮助开发者快速开发测试部署该项目，暂时只测试过macOS系统
3. 思考用`单体架构模式` 还是 `微服务架构模式`，项目小的情况下可以先用`单体架构模式`过度，后续再考虑`微服务架构模式`，若用`微服务架构模式`在开发测试阶段也可以用`单体架构模式`先过度节省机器资源
   - 单体架构中间件最小依赖: Mysql、Redis
   - 微服务架构中间件最小依赖: Mysql、Redis、Nacos
   - (可选) 可观测性: Grafana、Loki、Tempo
   - (可选) 定时任务: XXL-Job、Snail-Job、Redis
   - (可选) 异步队列: Redis、RocketMQ
