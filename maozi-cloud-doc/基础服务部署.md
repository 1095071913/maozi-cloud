# 基础服务部署

## 基础环境准备

1. 容器化部署（按操作系统选择对应方案）
   |操作系统|安装内容|
   |--|--|
   |Linux|Docker、Docker Compose|
   |Windows|WSL2、Docker Desktop|
   |MacOS|Docker Desktop|
2. 创建 Docker 虚拟网络
   ```
   docker network create maozi-cloud-network --subnet 172.19.0.0/16
   ```
3. 本地hosts文件添加
   ```
   127.0.0.1 maozi-cloud-basic-nacos
   127.0.0.1 maozi-cloud-basic-mysql
   127.0.0.1 maozi-cloud-basic-redis
   127.0.0.1 maozi-cloud-basic-xxljob
   127.0.0.1 maozi-cloud-basic-snailjob
   ```

## 基础服务部署

1. 进入 [docker-compose.yml](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-docker/maozi-cloud-basics-docker/docker-compose.yml) 所在目录
2. `单体服务`仅需部署 Mysql 与 Redis，其余基础服务看情况启动
   ```
   docker compose up -d maozi-cloud-basic-mysql
   docker compose up -d maozi-cloud-basic-redis
   ```
3. `微服务`需先部署 Mysql 服务
4. 导入 Nacos [数据库脚本](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-docker/maozi-cloud-basics-docker/maozi-cloud-basic-nacos/maozi-cloud-nacos-middleware-db.sql)
5. 导入 Seata [数据库脚本](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-docker/maozi-cloud-basics-docker/maozi-cloud-basic-seata/config/maozi-cloud-seata-middleware-db.sql)（非必要）
6. 在该 docker-compose.yml 中找到 `SEATA_IP=192.168.124.3`，将其修改为业务服务可访问到 Seata Server 服务的 IP；若业务服务能够天然访问到 Seata Server 容器内的 IP 服务，则直接删除 `SEATA_IP=192.168.124.3` 即可
7. 在该docker-compose.yml 中找到`/Users/maozi/Desktop/maozi-cloud-logs`修改成未来业务服务存放日志的地址，业务服务存放日志的地址在该[docker-compose.yml](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-docker/maozi-cloud-distributeds-docker/maozi-cloud-services-distributeds-docker.yml)中的`/Users/maozi/Desktop/maozi-cloud-logs`对应上
8. 导入 XXL-Job [数据库脚本](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-docker/maozi-cloud-basics-docker/maozi-cloud-basic-xxljob/maozi-cloud-xxljob-middleware-db.sql)（非必要）
9. 导入 SnailJob [数据库脚本](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-docker/maozi-cloud-basics-docker/maozi-cloud-basic-snailjob/maozi-cloud-snailjob-middleware-db.sql)（非必要，Web 控制台 http://localhost:8800/snail-job，默认账号 admin/admin）
10. 启动剩余基础服务
   ```
   docker compose up -d
   ```
