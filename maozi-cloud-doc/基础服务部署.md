# 基础服务部署

## 基础环境准备

1. 创建 Docker 虚拟网络
   ```
   docker network create maozi-cloud-network
   ```
2. 本地hosts文件添加
   ```
   127.0.0.1 maozi-cloud-basic-nacos
   127.0.0.1 maozi-cloud-basic-mysql
   127.0.0.1 maozi-cloud-basic-redis
   127.0.0.1 maozi-cloud-basic-xxljob
   127.0.0.1 maozi-cloud-basic-snailjob
   ```

## 基础服务部署

1. 进入 [docker-compose.yml](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-docker/maozi-cloud-basics-docker/docker-compose.yml) 所在目录
2. 先启动 Mysql 与 Redis，单体服务仅需依赖 Mysql 与 Redis
   ```
   docker compose up -d maozi-cloud-basic-mysql
   docker compose up -d maozi-cloud-basic-redis
   ```
4. （微服务）导入 Nacos [数据库脚本](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-docker/maozi-cloud-basics-docker/maozi-cloud-basic-nacos/maozi-cloud-nacos-middleware-db.sql)
5. （可选）导入 Seata [数据库脚本](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-docker/maozi-cloud-basics-docker/maozi-cloud-basic-seata/config/maozi-cloud-seata-middleware-db.sql)
6. （可选）导入 XXL-Job [数据库脚本](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-docker/maozi-cloud-basics-docker/maozi-cloud-basic-xxljob/maozi-cloud-xxljob-middleware-db.sql)
7. （可选）导入 SnailJob [数据库脚本](../maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-docker/maozi-cloud-basics-docker/maozi-cloud-basic-snailjob/maozi-cloud-snailjob-middleware-db.sql)
8. （可选）让宿主机业务服务能访问到容器内中间件 则需要设置 环境变量`APPLICATION_TO_REGISTER_IP=宿主机IP` 默认:容器地址
9. （可选）容器内业务服务日志映射宿主机目录 则需要设置 环境变量`APPLICATION_LOG_PATH=宿主机目录` 默认值:`maozi-cloud-script/maozi-cloud-deploy/maozi-cloud-deploy-docker/maozi-cloud-basics-docker/maozi-cloud-basic-promtail/maozi-cloud-logs`
9.  看情况启动剩余基础服务
   ```
   docker compose up -d
   ```
